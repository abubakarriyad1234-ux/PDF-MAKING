# PDF MAKING

ছবি ও PDF একসাথে করে একটি PDF বানানোর ওয়েবসাইট। সম্পূর্ণ বাংলায়, সম্পূর্ণ ব্রাউজারেই কাজ করে।

## ব্যবহার

1. এই রিপোজিটরির GitHub Pages লিংকটি খুলুন: https://abubakarriyad1234-ux.github.io/PDF-MAKING/
2. ছবি (JPG/PNG) বা PDF ফাইল যোগ করুন।
3. ড্র্যাগ করে বা উপরে/নিচে বোতাম দিয়ে সাজান।
4. পৃষ্ঠার আকার (A4/Letter), অভিমুখ, মার্জিন, ছবির মান বেছে নিন।
5. প্রিভিউ দেখে এক ক্লিকে PDF ডাউনলোড করুন।

## সীমা

- প্রতি ফাইল সর্বোচ্চ ২৫ মেগাবাইট
- সর্বোচ্চ ৫০টি ফাইল
- সর্বোচ্চ ৩০০ পৃষ্ঠা

## গোপনীয়তা

আপনার ফাইল কোথাও আপলোড হয় না। সবকিছু আপনার ব্রাউজারেই সম্পন্ন হয়।
